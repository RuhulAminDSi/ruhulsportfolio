## Setup Instructions

### Option 1: Deploy to GitHub Pages

1. Create a new GitHub repository named `username.github.io` (replace `username` with your GitHub username)
2. Clone this repository locally
3. Push the portfolio files to your GitHub repository:
   ```bash
   git remote add origin https://github.com/username/username.github.io.git
   git branch -M main
   git push -u origin main
   ```
4. Your portfolio will be available at `https://username.github.io`

### Option 2: Deploy to Netlify

1. Sign up for a free account at [Netlify](https://netlify.com)
2. Connect your GitHub repository
3. Netlify will automatically deploy your site
4. Your portfolio will be available at a Netlify subdomain

### Option 3: Deploy to Vercel

1. Sign up for a free account at [Vercel](https://vercel.com)
2. Import your GitHub repository
3. Vercel will automatically deploy your site
4. Your portfolio will be available at a Vercel subdomain

### Option 4: Deploy to AWS S3

1. Create an S3 bucket
2. Upload portfolio files
3. Enable static website hosting
4. Your portfolio will be available via S3 endpoint

## Customization

### Update Personal Information
Edit the following in `index.html`:
- Name and title
- Email address
- LinkedIn profile URL
- GitHub profile URL
- Experience details
- Project descriptions
- Skills and technologies

### Change Colors
Modify the CSS variables in `assets/css/styles.css`:
```css
:root {
    --primary-color: #2563eb;      /* Main blue */
    --secondary-color: #1e40af;    /* Darker blue */
    --accent-color: #f59e0b;       /* Orange accent */
    --dark-bg: #0f172a;            /* Dark background */
    /* ... more colors ... */
}
```

### Modify Sections
- Hero section: Update the main heading and subtitle
- Skills: Add/remove skill categories
- Projects: Add/remove project cards
- Experience: Update timeline items
